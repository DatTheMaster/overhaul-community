# Overhaul — Community

The public home for **Overhaul** — the game's bug reports, feature requests,
roadmap, and changelog.

## How to file a ticket

Tickets are opened through the **Discord feedback channel**. Post your report
there (screenshot + a sentence about what happened) and it lands here as a
public ticket, linked back into the conversation.

## What you'll find here

- **Bug reports** — what's broken, with the current status (`triage` → `in
  progress` → `shipped`)
- **Feature requests** — things you want, with 👍 votes guiding priority
- **Roadmap** — what's planned and what's in the works
- **Changelog** — what shipped, in plain language

## The rules of this repo

This is a public surface — the engineering happens elsewhere, privately. To
keep it that way:

- **No account data.** Don't post emails, usernames tied to accounts, or
  session material. Screenshots: crop out company names and anything personal.
- **No save files** — export/save data belongs in Discord DMs, not here.
- Ticket bodies are player-written; status and resolution comments are
  maintained by the bot.
- Duplicates are merged; `needs-info` tickets that go quiet get closed after
  a while.

## The pipeline, in one line

Discord feedback → public ticket here → triaged → fixed privately → the
resolution lands back on the ticket and in Discord.
